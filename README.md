# ないとマーケット（仮称）— 公開用

Netlify が配るのは、このリポジトリです。

**ここで中身を直さないでください。** 次の写しで消えます。
直すのは本体（`sasebo-2026`）の `site/` です。

```
sasebo-2026（private）        sasebo-2026-preview（public）
  site/            ───写す──→   ここ（リポジトリ直下）
  提案書・試算・記録  ───×──→   配らない
```

## このリポジトリが別になっている理由

本体には提案書・改訂指示書・打ち合わせの記録が入っています。
GitHub Pages を本体で使うには public にする必要があり、そうすると
**協賛の営業目標や損益分岐が外から読めます。** だからサイトだけを
別のリポジトリに置いています。
