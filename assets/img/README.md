# 画像の差し替えガイド

> ★重要：現在のヒーロー動画・写真には、旧名称「SASEBO CHRISTMAS MARKET 2026」のゲート看板が写っています。
> 名称が SASEBO LIGHTS FESTIVAL 2026 に変わったため、可能であれば新名称の素材に差し替えてください。

写真は `site/assets/img/photo/` に、**同じファイル名で上書き**するだけで差し替わります。
HTMLやCSSを編集する必要はありません。

現在入っているのは、ご提供いただいたイメージ画像から切り出したものです。
本番写真が用意できたら、下の推奨サイズに合わせて書き出し、同名で置き換えてください。

## 出店者カード

`vendor-01.jpg` 〜 `vendor-12.jpg` （各 800 × 600 / 4:3）

どの店にどの写真を出すかは `site/assets/js/data.js` の `vendors` 配列の `img` で指定しています。
店舗の実写が届いたら、`img` のパスを変えるか、同名で上書きしてください。

## ロゴ

`site/assets/img/logo/partner-01.svg` 〜 `partner-08.svg` はダミーです。
協賛企業のロゴ（**白背景・余白なし・PNGまたはSVG**）に差し替え、
`data.js` の `partners` でファイル名・企業名・リンク先を設定してください。
ロゴは白いカードの中で縦横比を保ったまま高さを揃えて表示されます。

## 動画

`site/assets/video/hero.mp4` がTOPのメインビジュアルで再生されます。

- 音声なし・ループ前提（5〜8秒程度）
- 目安5MB未満（現在 約2.6MB）
- 幅768px以上／省データ設定オフ／視差効果を減らす設定オフ のときだけ再生します
- それ以外では `hero.jpg` / `hero-mobile.jpg` の静止画のままです
- 再生中は右上に「動画を停止」ボタンが出ます

## 書き出しの目安

- 形式：JPEG（品質80前後）。WebP/AVIFに変換する場合はHTMLの拡張子も変更してください
- 夜の写真が中心のため、暗部がつぶれない程度に**やや明るめ**に書き出すと文字が乗ったときに見やすくなります
- 人物が写る写真は、公開の同意を得たものだけを使用してください

## 注意

現在の写真はすべて計画段階のイメージです。実際の会場写真ではありません。
その旨をフッターに記載しています（`tools/site_chrome.py` の `FOOT` 内）。
実写に差し替えたら、この注記を外してください。
